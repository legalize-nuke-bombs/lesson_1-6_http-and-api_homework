# Backend

Здесь находится локальный REST API на `json-server`.

## Запуск

```bash
npm ci
npm run dev
```

После запуска список матчей доступен по адресу:

```text
http://localhost:3000/matches
```

`db.json` изменяется после успешных запросов `POST`, поэтому новые матчи сохраняются между перезапусками API.
